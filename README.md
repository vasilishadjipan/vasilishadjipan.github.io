# Hi, I’m Vasilis

I’m an Android developer based in Nicosia, Cyprus. I build native apps with Kotlin and Jetpack Compose. My work spans retail loyalty apps and a personal investment calculator.

## Selected work

### Investment Calculator

I built an Android app that shows how contributions and compound interest change an investment over time.

* A stacked bar chart shows how the balance grows.
* A breakdown chart separates the money invested from the interest earned.
* A year-by-year schedule shows contributions, interest and closing balances.

[Get it on Google Play](https://play.google.com/store/apps/details?id=com.vasilis.investmentcalculator) · [View the source code](https://github.com/vasilishadjipan/InvestmentCalculator)

### Retail and loyalty apps
